# Oristar vertical preview — version 2

15-second, 1080×1920 Remotion treatment built from `video 1.mp4` only.

## Creative treatment

- Preserves the original source voiceover continuously from 00:00–00:15.
- Uses chronological source visuals with three editorial sections and gentle punch-ins.
- Adapts the reference's typographic grammar: condensed uppercase cyan/white type, green check marks, short key-idea phrases, and hard industrial cuts.
- Uses generated transition/check sound effects only. No music and no reference footage.

## Commands

```bash
npm run dev
npm run lint
npm run render
```

Output: `out/oristar-preview-v2.mp4`
