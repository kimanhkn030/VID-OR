# Frame direction

The full-height factory footage is the hero. Headlines sit left of the permanent top-right mark, in the upper-middle safe area. A small mono process code and short red rule create an industrial registration system. The cyan/white type treatment echoes the reference without reproducing any reference frame. Cards never obscure machine contact points or the final brand card.

## Tokens

- Ink: `#f7fbff`
- Oristar blue: `#12a7e8`
- Deep blue shadow: `#07385f`
- Registration red: `#ef3340`
- Process green: `#22c55e` used only on the visually supported dispatch beat
- Headline: Oswald/Arial Narrow fallback, 94–116 px, uppercase
- Label: IBM Plex Mono/monospace fallback, 21 px
